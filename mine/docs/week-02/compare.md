# week-02

## 与 hermes 实现对比

1. 当前实现参考了 hermes 的自动发现并注册工具实现：扫描特定目录并加载模块，使工具自注册到 registry。

2. 当前实现对工具名错误、工具参数错误处理比较简单，直接将错误消息交给模型，而 hermes 中会尝试重发请求来修复问题。而且在任意情况下当前实现都没有停止 turn，而 hermes 会在发现存在连续无效工具或参数内容存在截断时停止。

3. hermes 中会一次对一批 tool_calls 处理工具名和参数，本实现中逐个处理：先判定工具存在、然后确保输入格式为字符串、然后将字符串解析为参数字典、尽力将参数值转换为 schema 中要求类型、最后使用 handler 调用工具。
